# «Как надо» — сайт (копия 1:1)

Точная копия лендинга [remont-kak-nado.github.io](https://remont-kak-nado.github.io/) со всеми изображениями, видео, шрифтами, стилями и скриптами.

**Опубликован на GitHub Pages:** https://kaknado-pro.github.io/remont-kak-nado/

Репозиторий: [github.com/kaknado-pro/remont-kak-nado](https://github.com/kaknado-pro/remont-kak-nado)

## Запуск локально

Из папки проекта:

```bash
python3 -m http.server 8780
```

Затем откройте [http://127.0.0.1:8780](http://127.0.0.1:8780).

Можно также открыть `index.html` напрямую в браузере, но локальный сервер надёжнее для видео и скриптов.

## Что внутри

- `index.html` — главная страница;
- `assets/css/style.min.css` — стили;
- `assets/js/app.min.js` — слайдеры, модальные окна, квиз, карта и меню;
- `send.js` — валидация форм и отправка заявок в Telegram;
- `thankyou.html` — локальная страница «Спасибо» после отправки;
- `assets/img/agency-logo.png` — логотип Exponent Digital (шапка и подвал, ссылка на сайт агентства);
- `assets/img`, `assets/projects`, `assets/fonts` — изображения, видео и шрифты.

## Формы

Все формы (квиз, обратный звонок, общая форма) обрабатываются в `send.js`. По умолчанию заявки уходят на рабочий backend основного сайта (`remont-kaknado.ru/sendmail.php`) — туда же, куда шлёт форму действующий сайт компании. Сервер на стороне GitHub Pages не нужен.

Дополнительно можно включить дубль заявок в Telegram:

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой chat id (например, у [@userinfobot](https://t.me/userinfobot)).
3. Впишите их в начало `send.js`: `BOT_TOKEN` и `CHAT_ID`.

После этого каждая заявка будет приходить и в Telegram. Если токены не заполнены — заявки всё равно уходят в backend основного сайта.

Важно: токен бота в открытом JS-файле виден всем посетителям — не используйте бота с правами администратора.

## Важно

- Исходный HTML совпадает с опубликованным на GitHub Pages (коммит `ccdd482`); формы заменены на отправку в Telegram, а редирект «Спасибо» ведёт на локальную страницу `thankyou.html`.
