# «Как надо» — сайт (копия 1:1)

Точная копия лендинга [remont-kak-nado.github.io](https://remont-kak-nado.github.io/) со всеми изображениями, видео, шрифтами, стилями и скриптами.

**Опубликован на GitHub Pages:** https://voroninded1987-dot.github.io/remont-kak-nado/

Репозиторий: [github.com/voroninded1987-dot/remont-kak-nado](https://github.com/voroninded1987-dot/remont-kak-nado)

## Запуск локально

Из папки проекта:

```bash
python3 -m http.server 8780
```

Затем откройте [http://127.0.0.1:8780](http://127.0.0.1:8780).

Можно также открыть `index.html` напрямую в браузере, но локальный сервер надёжнее для видео и скриптов.

## Что внутри

- `index.html` — главная страница;
- `assets/css/style.min.css` — стили;
- `assets/js/app.min.js` — слайдеры, модальные окна, квиз, карта и меню;
- `send.js` — валидация форм и отправка заявок в Telegram;
- `thankyou.html` — локальная страница «Спасибо» после отправки;
- `assets/img/agency-logo.png` — логотип Exponent Digital (шапка и подвал, ссылка на сайт агентства);
- `assets/img`, `assets/projects`, `assets/fonts` — изображения, видео и шрифты.

## Формы

Все формы (квиз, обратный звонок, общая форма) обрабатываются в `send.js` и отправляются в Telegram через Bot API — сервер не нужен.

Чтобы заявки приходили:

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой chat id (например, у [@userinfobot](https://t.me/userinfobot) или отправив боту любое сообщение и открыв `https://api.telegram.org/bot<ТОКЕН>/getUpdates`).
3. Впишите их в начало `send.js`: `BOT_TOKEN` и `CHAT_ID`.

Пока значения пустые, формы работают в демо-режиме: телефон проверяется, показывается страница «Спасибо», но заявка никуда не уходит.

Важно: токен бота в открытом JS-файле виден всем посетителям — для этого сайта это допустимо, но не используйте бота с правами администратора.

## Важно

- Исходный HTML совпадает с опубликованным на GitHub Pages (коммит `ccdd482`); формы заменены на отправку в Telegram, а редирект «Спасибо» ведёт на локальную страницу `thankyou.html`.
- Дизайн, тексты, фотографии, логотип и другие материалы принадлежат компании «Как надо». Копия подходит для личного ознакомления и демонстрации; перед публичным размещением бренд и контент нужно заменить или получить разрешение правообладателя.
